## Fraud Protection Implementation

### Click Protection Layers

```
User Click on Affiliate Link
        ↓
    ┌───────────────────────────┐
    │ LAYER 1: Frontend Check   │  ← JS: 5-second interval
    │ (affiliate-click-protection.js)
    └────────────┬──────────────┘
                 ↓ (passes)
    ┌───────────────────────────┐
    │ LAYER 2: Request to API   │  ← /api/affiliate/click/{code}
    │ (AffiliateClickController)
    └────────────┬──────────────┘
                 ↓ (passes)
    ┌───────────────────────────┐
    │ LAYER 3: Deduplication    │  ← ClickDeduplicationService
    │ - Device fingerprint      │    6 checks:
    │ - Session check           │    ✓ Time window
    │ - Rate limits             │    ✓ Session dedup
    │ - Signature matching      │    ✓ Per-minute limit
    │ - Risk scoring            │    ✓ Per-hour limit
    │                           │    ✓ Signature match
    └────────────┬──────────────┘    ✓ Risk score
                 ↓ (passes)
    ┌───────────────────────────┐
    │ LAYER 4: Database Record  │  ← affiliate_fraud_logs
    │ - Store click attempt     │    affiliate_click_sessions
    │ - Log dedup info          │
    │ - Update statistics       │
    └───────────────────────────┘
                 ↓
         ✅ Click Recorded OR
         ❌ Click Rejected (fraud detected)
```

### Risk Scoring System

```
User Activity Risk Score Calculation:

Base Score: 0

If duplicate click detected:        +20
If excessive rate limit:            +30
If suspicious signature pattern:    +25
If outside normal time window:      +15
If multiple account patterns:       +20
If automation tool detected:        +40

Total Risk = Sum of all factors

Risk Levels:
├─ 0-29:   ✅ Safe (Normal user)
├─ 30-59:  ⚠️  Watch (Monitor)
├─ 60-79:  🔔 Alert (Flag for review)
└─ 80-100: 🚫 Block (Account suspended)
```
