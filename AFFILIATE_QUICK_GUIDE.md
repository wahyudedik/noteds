# 🎯 Affiliate Features - Quick Reference

## 🌐 LANDING PAGE - The Public Face

### Where to Access
```
Dashboard → Affiliate Link → Click PURPLE Button (🌐 Edit Landing Page)
```

### What It Is
A custom page that appears when people click your affiliate link. You control the design and message.

### Basic Workflow
```
You create: HTML Content + Slug
          ↓
System generates: URL like http://noteds.test/a/my-slug
          ↓
You share: The public URL
          ↓
People visit: They see your custom landing page
          ↓
They click: CTA button → Goes to affiliate link → Potential purchase
          ↓
You earn: Commission from the sale
```

### Example Landing Page URLs
- `http://noteds.test/a/special-50-percent-off`
- `http://noteds.test/a/evan-premium-notes`
- `http://noteds.test/a/best-notes-2024`

### Why Use It?
✅ Higher conversion rates (vs direct link)
✅ Build trust with custom messaging
✅ Track custom traffic source
✅ A/B test different offers
✅ SEO friendly for custom slugs

## 📦 PROMOTIONAL MATERIALS - The Toolkit

### Where to Access
```
Dashboard → Affiliate Link → Click ORANGE Button (📦 Promotional Materials)
```

### What It Is
Ready-to-use marketing assets (banners, code, ads) that make sharing easy. People can use these to promote your link.

### 3 Types of Materials

#### 1️⃣ BANNER IMAGES
**Use:** Social media, websites, blogs
**Size Options:** 728x90, 300x250, 468x60, or custom
**How:**
```
1. Enter material name: "50% Off Banner"
2. Select type: Banner Image
3. Choose size: 300x250
4. Upload PNG or JPG image
5. Click Create
6. Use: Download or copy the URL
```

#### 2️⃣ LINK CODE
**Use:** Websites, blogs, email, forums
**Format:** HTML anchor tag ready to embed
**How:**
```
1. Enter material name: "Text Link"
2. Select type: Link Code
3. Optionally paste custom HTML (or auto-generates)
4. Click Create
5. Use: Copy the code and paste into your website
```
**Example Generated Code:**
```html
<a href="https://noteds.test/?ref=YOUR_AFFILIATE_ID">
  Check out these premium notes
</a>
```

#### 3️⃣ TEXT ADS
**Use:** Forum signatures, email closing, document text
**Format:** Plain text or formatted text
**How:**
```
1. Enter material name: "Forum Signature"
2. Select type: Text Ad
3. Write your ad text or HTML
4. Click Create
5. Use: Copy and paste into forum signatures, emails, etc.
```
**Example Text Ad:**
```
"Discover premium digital notes from [Creator Name] - 
visit [landing-page-link] now!"
```

### Why Use Materials?
✅ Makes sharing easy for users
✅ Pre-formatted and ready to use
✅ Professional looking assets
✅ Increase reach across platforms
✅ Consistent branding across channels

## 🎯 BEST PRACTICES

### Landing Page
- ✅ Use clear, benefit-focused headline
- ✅ Include social proof (reviews, stats)
- ✅ Mobile-responsive design
- ✅ One clear call-to-action button
- ✅ Fast loading time
- ❌ Don't use complex navigation
- ❌ Don't redirect multiple times
- ❌ Don't make claims you can't prove

### Promotional Materials
- ✅ High quality images for banners
- ✅ Consistent branding/colors
- ✅ Clear benefit statement
- ✅ Professional appearance
- ✅ Multiple variations for testing
- ❌ No low-res or pixelated images
- ❌ No misleading claims
- ❌ No broken links

### Overall Strategy
- ✅ Test multiple materials (A/B testing)
- ✅ Track which channels perform best
- ✅ Update landing page based on feedback
- ✅ Refresh materials every 3-6 months
- ✅ Monitor your conversion rate
- ❌ Don't spam with same message
- ❌ Don't use deceptive practices
- ❌ Don't ignore analytics

## 🚀 START IN 5 MINUTES

   - Click create

   - Track clicks in dashboard

5. **Monitor & Optimize** (Ongoing)

   - A/B test different materials
   - Improve landing page based on feedback
   - Increase earnings over time
